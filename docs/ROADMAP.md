The current priority is a welcoming **opening → preflight pace selection → explicit Start → fixed-duration cleaning → automatic entry → reflection**. Keep the player inside, viewing dunes and Ren through a clear window. Preserve restrained Asian-inspired motifs and shared components; the earlier ornate dome references are archived design inputs, not a requirement to restore a crowded dashboard.

The 0.8 integration, source validation, exact-source packaging, hosted native launch/update gates, publication and public-file verification are complete. Future releases repeat these gates; physical-device usability and learning outcomes remain separate work. Website deployment was skipped by owner choice, so public hosting remains deferred.

The roadmap does not promise a complete curriculum, photoreal art, certified astronaut training, universal direct iOS distribution, or “200× better” measured outcomes. Performance evidence must name the version, renderer, device, and measurement. Older 0.7.1 startup improvements do not measure the new journey.

Postrelease design material is available as [result-screen copy](RESULT-SCREEN-COPY.md), [words-only equations](VIDEO-EQUATIONS-SIMPLE.md) and a [one-page PDF](media/KOMAKU-Video-Equations-Simple.pdf). These repository follow-ups were not built into the published ZIPs.

Parallel work uses explicit file ownership and serialized integration. See [team status](TEAM-STATUS.md), [journey contract](design-specs/JOURNEY-0.8.md), [request tracker](REQUEST-TRACKER.md), [downloads](DOWNLOADS.md), and [validation](VALIDATION.md).
