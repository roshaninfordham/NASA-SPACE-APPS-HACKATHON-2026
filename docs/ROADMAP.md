**0.7.0-alpha.1 is the current source candidate; publication is not yet established by this document.** The latest verified published baseline is [0.6.1-alpha.1](https://github.com/roshaninfordham/NASA-SPACE-APPS-HACKATHON-2026/releases/tag/v0.6.1-alpha.1), source `587d6c9fc7a5cd504b1c1ea68707628572bbbe4e`. [Team status](TEAM-STATUS.md), [downloads](DOWNLOADS.md) and the [changelog](../CHANGELOG.md) identify subsequent publication evidence.

The owner's latest visual pivot is now the active direction: a near-window indoor start overlooking only warm dunes and Mira, three first-screen choices and three main gameplay actions. A dedicated room and side airlock replace the visible exterior outpost in the default presentation; the simpler two-workstation EVA room is retained behind reversible flags. The ornate 0.6 references are historical inputs, not an instruction to restore every removed ring, panel or motif. The mission, local learning and update contracts remain intact.

The next product gates are design review, exact-source release acceptance, physical-device testing, science review and supervised learning evaluation. Completing the ten delivery outcomes does not mean that the full curriculum, final art, expanded rescue campaign or every platform is finished.

Parallel work uses explicit file ownership and serialized integration. Contribution counts reflect meaningful work; empty commits are not a delivery goal.
