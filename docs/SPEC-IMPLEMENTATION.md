# Design specification implementation ledger

**Reviewed November 14, 2026.** This ledger covers the three new [design-team specifications](design-specs/README.md) for **<!-- brand:display_name -->KŌMAKU: Shield Protocol<!-- /brand -->**. It distinguishes checked-in implementation from the documents' broader visual and gameplay targets. A source file or passing structural test does not establish visual identity with a concept image, frame-rate performance, scientific validation or a published release.

These increments are included in alpha 0.6.0-alpha.1. [Team status](TEAM-STATUS.md), [downloads](DOWNLOADS.md) and release evidence identify the exact source and tested platforms.

## How to review the new work

1. Open the existing game and use habitat exploration to compare silhouette, doorway clearance, control-room framing and instrument readability.
2. Open the habitat inspection interface; follow all four architectural topics and check each explanation against the visible structure and current simulation limitations.
3. Open the Suit Lab; inspect each view and cosmetic theme, run all five exercises, and return to the game. Check portrait and landscape controls independently.
4. Confirm the console changes with actual mission state rather than copied reference-image values. Ensure an optional practice interface does not advance the mission while it is paused.
5. Use the [media procedure](MEDIA.md) to capture the real renderer. Compare composition, palette, motifs, material response, text readability and navigation separately. A pleasing camera capture does not establish full walkable-scene fidelity.

The individual scene/model tests supply repeatable structural and numerical checks. Integrated tests must cover route traversal, input/focus, pause/resume, narrow-screen bounds, import/export and updater compatibility. Do not mark a physical device or image-match criterion passed from a headless run.

## Remaining work in dependency order

| Milestone                | Concrete deliverable                                                                                            | Completion evidence                                                                          |
| ------------------------ | --------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------- |
| Art-direction review     | Agree hero cameras, shell scale, motif placement and revised character proportions with the design team         | Annotated in-engine comparisons; unresolved deviations recorded                              |
| Artist asset pipeline    | Blender/GLB source, UVs, texture maps, trim sheets, licensing and stable pivots                                 | Importable source/export pairs; asset manifests; collision review                            |
| Pressure/entry design    | Specify sealed geometry and safe simplified airlock behavior without breaking existing routes                   | State-machine tests, blocked double-open path, cancellation/recovery and walkthrough capture |
| Character production     | Skeleton, expressive original face, animation set, cloth/hair fallbacks and measured LODs                       | Animation/LOD captures and platform render budgets                                           |
| New scenarios            | Define one coherent time scale and models for any oxygen, water, thermal, construction or multi-sol progression | Documented assumptions, meaningful model tests and age-appropriate playtests                 |
| Audio/accessibility      | Original/licensed ambience and action cues, readable/captioned alternatives, input review                       | Attribution, mute/reduced-motion behavior, keyboard/touch and user testing                   |
| Optimization and release | Real desktop/mobile profiling, renderer fallbacks, reproducible captures and signed build validation            | Device matrix, frame-time/memory evidence, release hashes and update acceptance              |

These are production milestones, not a promise that a multi-week art and gameplay roadmap was completed in a single parallel coding pass.
