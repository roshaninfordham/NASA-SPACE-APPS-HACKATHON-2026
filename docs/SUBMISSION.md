The current mission puts a player aged 7–12 inside an outpost, looking through a window at Ren cleaning a solar panel. The player adjusts cleaning pace and watches dust removal, power, stored energy, and time. A fictional tiredness model changes effective cleaning speed. Ren enters automatically after about 90 active real seconds, representing 30 mission minutes. The outcome uses cleaned fraction; the fixed outside duration gives every completed run the same absorbed model dose.

The released interface includes an optional eight-concept Science library. The 0.11 candidate restores eight visible, updating science bubbles around the mission view and has passed source checks; this page does not claim publication. Earlier EVA, visor-cleaning, recall, and two-battery demonstrations do not describe the current submission mission.
