## Completion boundaries

The [ten-outcome roadmap](ROADMAP.md) describes delivery work, not a finished product. More curriculum, expanded rescue interactions, a production character rig, composed audio, independent oxygen/water/pressure models, physical-device performance, accessibility and measured educational outcomes remain open. Startup recovery establishes only its tested checkpoint.

The [specification ledger](SPEC-IMPLEMENTATION.md) explains why the latest visual pivot takes precedence over older exact screen counts and ornament instructions. The scientific mission rules are retained rather than silently altered to match an image.
