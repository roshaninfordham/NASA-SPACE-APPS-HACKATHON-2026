# KŌMAKU: Dust & Radiation — 0.10.0-alpha.1

**Interface and installation update; publication pending.** This version gives the cleaning mission a simpler first view while keeping the same 90-second standard round and scientific equations. The 0.9.0 assets remain unchanged; this is a separate release.

## What changes for a player

- **Three main readings and one pace control.** See panel cleaning, stored energy and the real-time storm countdown. Use the red stepped slider or Slower/Faster to guide Ren; the brush and panel remain visible.
- **Science when you want it.** Science pauses the mission and opens all eight concepts. A short explanation, diagram and everyday analogy come first. Learn more reveals the full model; Data & sources keeps the original evidence accessible separately. Reading is optional and has no completion gate.
- **Shorter story and result screens.** Three illustrated scenes lead to preflight. At the deadline Ren enters and the result appears immediately. See how science connects merges the ideas into four short relationships; Explore my numbers and graphs opens the precise equations and actual run. Back, retry and Home remain available.
- **Clear preparation and navigation.** Opening the window… represents actual scene preparation, with Back to Home cancellation. Pause, source viewing and return paths keep the whole simulation frozen while reading.
- **Softer feedback.** Original pace, discovery and card cues support actions, with cooldowns and reduced optional feedback. Existing visual warnings and priority alert beeps remain. Pause, focus loss and mute stop audio as specified; the unavailable Drive recording is not claimed as bundled.

The fixed mission still represents 30 simulated minutes; Time → Learn more explains that clock. WIN requires at least 80% cleaned, PASS at least 40%, otherwise TRY AGAIN. Ren is inside in every outcome. Stored energy and model dose explain the run; neither adds a hidden success condition. All completed default rounds share 10.9375 µGy model dose.

## Correct installation instructions

The 0.9.0 download was published with a bundled guide that still foregrounded 0.8 links and executable names. This package names its own actual files:

- Mac: **`KŌMAKU- Dust and Radiation.app`**, with the matching **Install KŌMAKU.command** helper.
- Windows: **`KOMAKU-Dust-and-Radiation.exe`**.
- Linux: **`KOMAKU-Dust-and-Radiation.x86_64`**.
- Versioned download links and package identity: **0.10.0-alpha.1**.

Historical instructions are separate. All three fingerprint-checked science/equation PDFs are included. Existing progress, app IDs, runtime compatibility and signing trust remain stable. After publication, compatible desktop users can install signed content through **Update available → Install → Restart**; existing OS app filenames need not change.
